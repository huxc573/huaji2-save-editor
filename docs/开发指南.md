## 1. 环境与命令

```powershell
# 依赖：Windows + Python 3.10+ + .NET Framework 4.x（自带 csc.exe），无第三方 pip 包
#       打包 exe 额外需要一个装了 PyInstaller 的解释器（本仓库用 ..\.venv，Python 3.14）
python tools/build_host.py        # 编译 src/XJCodec32.exe（改动 xj_codec32.cs 后必做）
python tools/run_tests.py         # 一键跑全部回归（13 组）
python tools/run_tests.py gui     # 只跑名字含 gui 的那几组
python src/xj_viewer.py           # 开界面
python tools/build.py             # 打包 exe（含自检）
python tools/test_dist.py         # 只验证 dist\ 里的 exe 能独立跑
python src/xj_db.py --out csv     # Data 数据表 → CSV
```

⚠ 本工作区路径含 `!` `【】[]` 与中文，**在终端里跑上面这些命令时要特别小心**：

* `run_in_terminal` 会把命令包进 `powershell.exe -Command "…"`，双引号会被吃掉，
  含 `!`/中文的路径经它一传就变形（`【尝鲜版】` → `` `[尝鲜版`] ``）。
  可行的写法是 `Set-Location -LiteralPath '<仓库>'` 先切目录（用单引号），
  然后一律用**相对路径**：`cmd /c ""D:\Dev\Python\...\python.exe" tests\test_gui.py"`。
* PS 5.1 里相对路径 + `-LiteralPath` 在“当前目录含 `[]`”时会报“对象不存在”，
  删文件用 `python tools\rmfile.py <相对路径>`。
* 测试脚本要弹窗的地方（GUI）必须把 `xj_viewer.messagebox` 换成记录函数，
  否则隐藏窗口上的模态框会把测试挂死（看不到、点不了）。

找不到游戏目录时：`$env:XJ_GAME = "<游戏根>"`（含 `Game.exe` 的那层）。

## 2. 数据流

```
save.rvdata2 (密文)
   │  xj_codec.decrypt_file()
   │     └─ subprocess → src\XJCodec32.exe → System\main.dll!decryption_file
   ▼
明文 Marshal 字节流
   │  xj_marshal.parse_stream()      （多个顶层对象首尾相接，逐个重置链接表）
   ▼
Doc.objects: [{'head','node','links'}]
   │  界面：xj_viewer 建树 / 改值 → xj_edit.PatchEngine.set_scalar()
   │        （等宽标量值 → 区间补丁）
   │  结构性修改（背包增删物品、新建 Change 对象…）→ doc.mark_structural()
   │        → xj_marshal.serialize_doc(objects) 整个文档重写（带符号表，字节级一致）
   ▼
xj_edit.PatchEngine.apply() 或 xj_marshal.serialize_doc()   → 新明文
   │  xj_marshal.parse_stream() 再解析一次（解析不过就拒绝写）
   │  xj_codec.encrypt_file()
   ▼
写回 save.rvdata2（原文件自动备份为 .bak.<时间>）
```

## 3. 各模块职责

| 模块 | 职责 | 注意 |
|---|---|---|
| `xj_env.py` | 定位游戏目录 / `main.dll` / 存档 | **不要用 glob**（路径含 `【】[]`，`[` 会被当字符类） |
| `xj_codec.py` | 驱动 `XJCodec32.exe` | 只通过进程通信，不在本进程加载 DLL；打包后宿主在 exe 旁边或 `dll\` |
| `xj_codec32.cs` | 32 位宿主 | 字符串参数**必须 UTF-8**；路径要用绝对路径 |
| `xj_marshal.py` | Ruby Marshal 4.8 | 节点带 `start/end` 字节区间，是"区间补丁"的基础；`serialize_doc()` 是**字节级重写**（带 symtab） |
| `xj_edit.py` | 区间补丁 | 标量走 `set_scalar`（按节点类型赋值，`assign_value`）；**长度变化**的修改走 `serialize_doc` |
| `xj_model.py` | 语义层 Doc | `structural` 标记；写回前会再解析一次，解析不过就不写 |
| `xj_save.py` | 存档语义层 | `SaveDoc(doc=…)` 必须把界面的 Doc 传进来，否则改的是另一份内存副本 |
| `xj_aes.py` | AES-128-ECB（纯 Python） | 只用来读写 `Change` 里的物品计数校验；密钥 `admin_1941344749` |
| `xj_game.py` | 游戏层（存银/背包/经验/召唤兽/防作弊） | 改背包后必须 `resync_security()` 或逐个 `sync_security_item()`，否则物品计数校验对不上 |
| `xj_nodes.py` | 节点 → 人能看懂的文字 | `key_label()` / `note_for()`；`[None]` 就是没走这里造成的 |
| `xj_notes.py` | 全部中文注释 / 上限常量 | `SWITCH_NAMES` / `VARIABLE_NAMES` 是游戏自己写在脚本里的名字 |
| `xj_db.py` | `Data\*.rvdata2` → CSV | 表定义在 `TABLES`（列 = `(中文表头, 取值说明)`），加列只改这一处 |
| `xj_viewer.py` | 界面（9 个页签） | 不改数据，只调 Doc / SaveDoc / GameEditor；数据树是**懒加载**的 |

### 界面里的几个约定

* `App(root, save_path=None)` —— 不是 `Tk` 子类，`App` 只包住一个 `root`；
  关窗口要 `root.destroy()`。
* 页签 Frame 都存成属性（`tab_quick` / `tab_tree` / `tab_actor` / `tab_party` /
  `tab_baby` / `tab_switch` / `tab_db` / `tab_help` / `tab_log`），方便测试当锚点。
* `refresh_panels()` 把 7 个面板逐个刷，**每步单独 try**：一个面板出错不能连坐
  “全部解析数据”。
* 数据树：`CHILD_LIMIT`（300）配合 `<<TreeviewOpen>>` → `_fill_children()`；
  搜索走的是模型层（`_walk_search`，不进 Treeview），命中后用 `_reveal()` 展开路径。
* 所有 Tk 回调的未捕获异常走 `root.report_callback_exception = _tk_exception`
  → 写 `error.log` + 弹框 + 状态条 （打包成 exe 后不然就是“点了没反应”）。
* `App._guess_save()` 会读 `~/.huaji2_save_editor_last.txt`（上次打开的文件）。
  **自检时别被它带偏**：`selftest_lines()` 按 `XJ_SAVE` → 游戏目录 save.rvdata2
  的顺序重载一遍。

## 4. 加一个新功能的一般步骤

1. **先确认格式**：写个 `probes/probe_XX_*.py`，把结论落到 `docs/存档格式.md`。
   不要凭猜改写存档 —— 一个字节错位就会让游戏报
   `TypeError: cannot convert Array into String`，而且**字节层看不出来**。
2. **在 `xj_model.py` 里加语义方法**（例如 `set_gold`），内部用
   `xj_edit` 的补丁接口，不要直接拼字节。
3. **写测试**：`tests/` 下加一条，样本优先用游戏自带的明文文件
   （`Logs\Battle\*\Battle.bt2`），或在临时目录里造。
4. **界面**：在对应页签加控件，调 `Doc` 的方法。
5. **更新** `README.md` / `CHANGELOG.md`。

## 5. 最容易写坏存档的四件事

1. **Marshal 对象链接 `@N`**
   Ruby 存盘时同一个对象第二次出现只写一个编号。动了某个对象内部的成员数量，
   后面所有编号都会错位。⇒ 结构性修改一律走
   `xj_marshal.serialize_doc(objects)` 重新编号（写字节级重写）；
   能等宽的才做**标量区间补丁**。
2. **非 ASCII 符号只在“定义”处包装**
   `I` 类型里写符号：`I :名字 <e> :E T`（`e` = UTF-8）；
   后续引用只能写裸 `;N`。给“符号定义”加 `I` 头、给链接也加 `I` 头，
   都会让字节数和 Ruby 的解释完全变样（见 `emit_sym` / `sym_body`）。
3. **改完必须再解析一次**
   `Doc.save()` 里 `M.parse_stream(new)` 就是这道闸；解析不过直接抛异常、不写盘。
4. **`RPG::Table`（`u` userdef）里的二进制块**
   当成不透明数据原样保留，**不要解码也不要重排**。

**校验口径**：`tools/test_roundtrip.py` 要求“解析 → 重写”与原始密文解密后的明文
**逐字节相同**（17/17）；`tools/test_semantic_equal.py` 要求语义树等价（39/39）。
改了 `xj_marshal.py` 两个都要跑。

## 6. 打包成 exe

```powershell
python tools\build.py              # 编宿主 + 准备 dist + PyInstaller + 临时目录自检
python tools\build.py --dll-dir    # 宿主放进 dist\dll\（依赖多的时候用）
python tools\build.py --nopack     # 只编宿主、只准备 dist
python tools\test_dist.py          # 单独重跑 exe 自检（会打印 selftest_result.txt）
```

要点：

* 解释器：优先 `$env:XJ_PY`，否则找仓库旁的 `..\.venv\Scripts\python.exe`，
  再否则用当前解释器；**必须装了 PyInstaller**。
* tcl/tk 的脚本库不会自动收集，`tcl_data_args()` 手动 `--add-data`。
* `--onefile --windowed`，产物 `dist\画迹2存档工具v0.4.exe`（约 13 MB）。
* **`XJCodec32.exe` 必须和主 exe 挨着**（或放 `dll\`、`bin\`、`依赖DLL\`）；
  自检里会报“32 位宿主”是一项。
* **`main.dll` 绝对不打进去**：有版权、而且它会联网上报；
  只让 32 位宿主去游戏目录加载它。
* 自检 = 把整个 dist 拷到**临时目录**跑 `XJ_SELFTEST=1`，
  并清掉 `PYTHONHOME/PYTHONPATH/VIRTUAL_ENV`（不然 PyInstaller 引导会失败）；
  因为临时目录里找不到游戏，会把 `XJ_GAME`/`XJ_SAVE` 喂给它。
  跑完读 `selftest_result.txt`，最后一行必须是 `结果: OK`。

## 7. 平台坑（Windows + 中文/特殊字符路径）

* 终端/脚本里路径一律用绝对路径 + `-LiteralPath`；
  `Set-Location`/`cd` 对含 `[]` 的路径会失败。
* PowerShell 5.1 控制台是 GBK：Python 里 `print` 中文/符号会 UnicodeEncodeError；
  探针统一 `sys.stdout.reconfigure(errors='replace')` 并**写文件再读**。
* `Start-Process -FilePath` 遇 `[]` 当通配符 → 用
  `[System.Diagnostics.Process]::Start($psi)`。
* 旧 exe 被占用导致 csc 写不进去 → 换输出名或先 `Stop-Process`。
