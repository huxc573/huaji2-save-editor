# 开发指南

给以后改这个仓库的人（包括未来的我）。

---

## 1. 环境与命令

```powershell
# 依赖：Windows + Python 3.10+ + .NET Framework 4.x（自带 csc.exe），无第三方 pip 包
python tools/build_host.py        # 编译 src/XJCodec32.exe（改动 xj_codec32.cs 后必做）
python tests/test_marshal.py
python tests/test_codec.py
python tests/test_model.py
python tests/test_gui.py
python src/xj_viewer.py           # 开界面
```

找不到游戏目录时：`$env:XJ_GAME = "<游戏根>"`（含 `Game.exe` 的那层）。

## 2. 数据流

```
save.rvdata2 (密文)
   │  xj_codec.decrypt_file()
   │     └─ subprocess → src\XJCodec32.exe → System\main.dll!decryption_file
   ▼
明文 Marshal 字节流
   │  xj_marshal.parse_stream()      （多个顶层对象首尾相接，逐个重置链接表）
   ▼
Doc.objects: [{'head','node','links'}]
   │  界面：xj_viewer 建树 / 改值 → xj_edit.PatchEngine.set_scalar()
   ▼
xj_edit.PatchEngine.apply()   → 新明文
   │  xj_marshal.parse_stream() 再解析一次（解析不过就拒绝写）
   │  xj_codec.encrypt_file()
   ▼
写回 save.rvdata2（原文件自动备份为 .bak.<时间>）
```

## 3. 各模块职责

| 模块 | 职责 | 注意 |
|---|---|---|
| `xj_env.py` | 定位游戏目录 / `main.dll` / 存档 | **不要用 glob**（路径含 `【】[]`，`[` 会被当字符类） |
| `xj_codec.py` | 驱动 `XJCodec32.exe` | 只通过进程通信，不在本进程加载 DLL |
| `xj_codec32.cs` | 32 位宿主 | 字符串参数**必须 UTF-8**；路径要用绝对路径 |
| `xj_marshal.py` | Ruby Marshal 4.8 | 节点带 `start/end` 字节区间，是"区间补丁"的基础 |
| `xj_edit.py` | 区间补丁 | 标量走 `set_scalar`；**长度变化**的修改才需要整块重写 |
| `xj_model.py` | 语义层 Doc | 写回前会再解析一次，解析不过就不写 |
| `xj_viewer.py` | 界面 | 不改数据，只调 Doc |

## 4. 加一个新功能的一般步骤

1. **先确认格式**：写个 `probes/probe_XX_*.py`，把结论落到 `docs/存档格式.md`。
   不要凭猜改写存档 —— 一个字节错位就会让游戏报
   `TypeError: cannot convert Array into String`，而且**字节层看不出来**。
2. **在 `xj_model.py` 里加语义方法**（例如 `set_gold`），内部用
   `xj_edit` 的补丁接口，不要直接拼字节。
3. **写测试**：`tests/` 下加一条，样本优先用游戏自带的明文文件
   （`Logs\Battle\*\Battle.bt2`），或在临时目录里造。
4. **界面**：在对应页签加控件，调 `Doc` 的方法。
5. **更新** `README.md` / `CHANGELOG.md`。

## 5. 最容易写坏存档的三件事（huaji1 的血泪教训，画迹2 同样适用）

1. **Marshal 对象链接 `@N`**
   Ruby 存盘时同一个对象第二次出现只写一个编号。动了某个对象内部的成员数量，
   后面所有编号都会错位。⇒ 凡是"整块替换"都要用自包含序列化
   （`xj_marshal.serialize()` 会把链接全部展开成独立副本），
   或者只做**等宽的标量区间补丁**。
2. **改完必须再解析一次**
   `Doc.save()` 里 `M.parse_stream(new)` 就是这道闸；解析不过直接抛异常、不写盘。
3. **`RPG::Table`（`u` userdef）里的二进制块**
   当成不透明数据原样保留，**不要解码也不要重排**。

## 6. 打包（v0.2 待做）

参考 huaji1 的做法：PyInstaller 打包 `xj_viewer.py`，把 `XJCodec32.exe`
一起带上，**不要**把 `main.dll` 打进去（有版权，而且会联网上报），
运行时从用户自己的游戏目录加载。

## 7. 平台坑（Windows + 中文/特殊字符路径）

* 终端/脚本里路径一律用绝对路径 + `-LiteralPath`；
  `Set-Location`/`cd` 对含 `[]` 的路径会失败。
* PowerShell 5.1 控制台是 GBK：Python 里 `print` 中文/符号会 UnicodeEncodeError；
  探针统一 `sys.stdout.reconfigure(errors='replace')` 并**写文件再读**。
* `Start-Process -FilePath` 遇 `[]` 当通配符 → 用
  `[System.Diagnostics.Process]::Start($psi)`。
* 旧 exe 被占用导致 csc 写不进去 → 换输出名或先 `Stop-Process`。
