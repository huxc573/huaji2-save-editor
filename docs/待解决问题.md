## ❌ 还没做的（按优先级）

### 1. 孵化蛋的抽取规则未适配 ⭐ 最该修

游戏按 `$baby[i][:allow_lv]` 分三档动态筛：

```ruby
list = [*21..23, *25..134, *310..354, *400..433] - [336,337,416, *418..421, 423]
id: [ list.select{ (0..55)   === $baby[i][:allow_lv] },   # 初级蛋 110
      list.select{ (56..125) === $baby[i][:allow_lv] },   # 中级蛋 111
      list.select{ (126..160)=== $baby[i][:allow_lv] },   # 高级蛋 112
      BabyManager.select_babys{ (135..170)===b.id and
                 $baby[b.id][:type2].fast_in?(:神兽资质,:神兽资质2) }  # 神兽蛋 113
    ][i].sample
mutation: rand < 0.08 && i < 3      # 前三档才有 8% 变异
```

**卡在哪**：`$baby` 表在 V2.201 里是**运行时动态生成**的
（脚本里只读不赋、`Data\` 下也没有 `Babies.rvdata2`），静态分析拿不到 `allow_lv`。

**现状**：工具沿用尝鲜版的硬编码号段（`src/itemattr.py`），
抽出来的召唤兽**可能对不上游戏**。加进去的蛋属于「运行时内容」，
游戏用的时候会按 `item.data` 取 id —— **id 不在对应档位内就等于给错东西**。

**怎么解**（二选一）：
- **A** 用 jruby 实跑一次游戏脚本，把运行时 `$baby` dump 出来
  （`画迹\tools\rubycheck\jruby-complete.jar` + JDK17 已在）；
- **B** 放弃自动生成，改成**只允许手动指定 id**（现在界面已有「孵出/开出对象 id」输入框）。

### 2. 召唤兽资质是估算值

同样因为 `$baby` 拿不到，`新增召唤兽` 里 107 种的六项资质是
**按id 区间 + `SPECIES` 同档位近似**的（`tables/baby_aptitude.py` 的 `_v201_fallback`）。
加出来后可在召唤兽页手动修正。界面已明确提示「资质为估算值」。

### 3. 坐骑未支持

`Data\Actors` 的 256~309（汗血宝马 / 镇塔之灵 / 葫芦灵兽…）是**坐骑**，
游戏里是另一种道具，不在召唤兽体系里。工具目前**完全没做**坐骑编辑
（`新增召唤兽` 列表里也明确排除了它们，见 `is_baby_entry()`）。

### 4. 技能 / 装备的可视化编辑

`@skills`（id 数组）、`@equips`（6 个 `Game_BaseItem`）现在只能看，改要进数据树。

### 5. 写回字符串时补`:E => true` 编码 ivar

现在写字符串不附带编码 ivar。对 ASCII 名字没影响，
但**要把名字改成中文**时游戏可能按"ASCII 字符串"读 —— 需要时再补。
（规则见 `docs/开发指南.md` §5。）

### 6. GUI 便捷操作

搜索结果的「上一个/下一个」、批量改数组、「把 N 个物品数量一键×10」等。
背包已能批量设数量/模板写入，但还不能多选几格一起改。

### 7. CSV 的进阶用法

把 `@effects` 里的 id 换成对应名字（`解除状态#1` → `解除状态#1 中毒`），
需要跨表引用（`Item.@effects` → `States.rvdata2`）。

## 已知限制（不是 bug）

- **游戏运行中改存档无效**：它只在存/读档时读文件。
- **V2.201 没有周期检查、没有作弊标记、没有物品记账校验** ——
  脚本里 `cheated` / `$jiance` / `security` 三者零命中，存档里也没有
  `@cheated` / `@keyword` 字段。**内测版仅有 Lock 校验和一层**。
  ⇒ 改钱/改背包不会被游戏逮到，但仍建议别改太离谱。
- 改了存档内容后**不要**去改 `System\main.dll` / `Data\main.rvdata2`。
- `@config[:hard_disk_code]` 记的是**建档时那台机器**的机器码。
  离线版用 Ruby 替身返回固定码，所以和本机真码（`630693299`）不同是正常的；
  体检那条「机器码不匹配」不影响游戏，只是个提醒。
