画迹2 存档修改器 v0.2 —— 使用说明
=================================

一句话：解密游戏存档 → 想改啥改啥 → 再加密写回去，连游戏的防作弊校验一起修好。


【怎么用】
  1. 先关掉游戏（游戏只在存/读档时读文件，开着改没用）。
  2. 双击运行（需要装 Python 3.8+ 64 位，不用装任何第三方库）：
         python src\xj_viewer.py
     或者直接用命令行看概览：
         python src\xj_save.py
  3. 界面会自动找到游戏和 <游戏根>\save.rvdata2。
     找不到就设环境变量 XJ_GAME 指向游戏目录。
  4. 三个页签：
        概览      存档概况、环境信息、加解密自检
        快捷修改  金钱 / 角色等级·HP·MP·名字 / 开关 / 变量 / 防作弊校验一键修复
        数据树    所有字段的树形浏览，双击任意标量字段就能改
  5. 改完按 Ctrl+S 保存。原文件会自动备份成 save.rvdata2.bak.<时间戳>。


【金钱为什么能随便改】
  游戏的金钱其实是一个 Lock 对象，里面存了 @value（数值）和 @master（校验和）：

      @master = @value * 91 + 45 + seed / 800      （seed 存在存档里的 :system 分区）

  读金钱时它会验算一遍，不相等就弹「游戏异常！」然后退出。
  本工具改 @value 时会自动把 @master 一起重算；
  「检查并修复防作弊校验」按钮还会扫描整个存档，把所有不一致的地方都修好。

  万一你还是看到了「游戏异常！」：
    回到工具里点一次「检查并修复防作弊校验」，保存，再进游戏。


【想改的字段在哪儿（数据树页）】
  :party    → @gold 金钱、@actors 队伍成员、@items 物品、@steps 步数
  :actors   → @data[角色id] → @name 名字、@level 等级、@hp、@mp
  :switches → @data[开关编号]  （编号从 0 开始）
  :variables→ @data[变量编号]


【出问题了怎么办】
  * 存档坏了：把同目录下的 save.rvdata2.bak.<时间戳> 改回 save.rvdata2 即可。
  * 提示解密失败：可能是游戏更新过、换了密钥，见 docs\逆向过程.md 里的爆破工具。
  * 只改存档是安全的：游戏只对 Game.exe 和 System\main.dll 做 md5 校验，
    不会校验存档本身。
