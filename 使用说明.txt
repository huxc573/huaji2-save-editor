画迹2 存档修改器 v0.4 —— 使用说明
=================================

一句话：解密游戏存档 → 存银 / 背包 / 角色经验 / 召唤兽随便改 →
再加密写回去，连游戏的防作弊校验（物品计数校验、周期检查）一起修好；
顺带把 Data 目录的数据表转成 CSV，查物品 id / 描述 / 效果很方便。

v0.4 新增：存银、背包 4 页×20 格（改数量/清空/添加物品，自动同步计数校验）、
         角色「获得经验」（可突破等级上限）、召唤兽（等级/气血/魔法/六项资质/
         忠诚/寿命/成长/五维）、防作弊体检（一键按规则修复 + 清除 @cheated）。


【怎么用】
  一、直接跑 exe（不装 Python，推荐）
      dist\画迹2存档工具v0.4.exe
      必须和 XJCodec32.exe 放在同一个目录（或 dist\dll\ 子目录里）。
      若 exe 找不到宿主会提示“找不到 XJCodec32.exe”并列出去哪找。

  二、用源码跑（要装 Python 3.8+ 64 位，不用装任何第三方库）
         python src\xj_viewer.py
     或者直接用命令行看概览：
         python src\xj_save.py

  1. 先关掉游戏（游戏只在存/读档时读文件，开着改没用）。
  2. 界面会自动找到游戏和 <游戏根>\save.rvdata2。
     找不到就设环境变量 XJ_GAME 指向游戏目录。
  3. 九个页签（顺序和画迹1 的编辑器一致）：

        概览 / 快捷修改   存档概况 + 存银 / 步数 / 存档次数 / 战斗次数
                         防作弊体检：表格按游戏规则列出每一项是否正常，
                         下面四个键：体检 / 一键按规则修复 / 清除作弊标记 /
                         同步物品计数校验
        全部解析数据      所有字段的树（点三角展开、双击字段名看详情）
                         顶部搜索框：输入名字/字段（如 @gold、体质）回车，
                         结果列表里双击就跳到那一条；右键可改值 / 复制路径
                         字段名不再是 [None]，全部带中文注释
        角色 / 属性       上面选角色，下面改基础字段（含 @exp 获得经验）和五维
                         快捷按钮：满级(60) / 经验+10000 / 回满 HP·MP / 属性全 +10
        背包 / 物品       先选「背包1~4」和「道具/武器/防具」，下面是 20 个格子：
                         双击格子改数量；选中后可直接改数量 / 添加物品 / 清空格子
                         添加/清空会自动同步物品计数校验（Change 对象）
        召唤兽            选角色 → 选召唤兽；20 个字段：等级/气血/魔法/TP/经验/
                         六项资质/忠诚/寿命/成长/五维
                         快捷按钮：满级(65) / 回满 / 忠诚满 / 寿命满 /
                                   六项资质+100 / 五维+10
        开关 / 变量       双击即改；带游戏自己的名字，例如
                         #1 MAP_SCROLL 地图卷动、#2 PLOTING 剧情进行中，
                         变量 #1 CHOICS_COLUMN 选项列数、#2 DIALOGUE 对话
        数据表 (CSV)      10 张 Data 表的预览 + 导出 CSV（见下）
        说明 / 机制       密钥、存档结构、防作弊原理（就是本文件的精简版）
        更新日志          版本更新记录
  4. 改完按 Ctrl+S 保存（或点「保存修改」）。
     标题栏出现 * 表示有未保存的修改；点「放弃修改」＝重新载入。
     原文件会自动备份成 save.rvdata2.bak.<时间戳>。


【Data 目录下的数据表 → CSV】
  Data\*.rvdata2 全都是加密的（密钥 761205），工具会自动解密 + 解析 + 转 CSV：
      Items 物品、Weapons 武器、Armors 防具、Skills 技能、States 状态、
      Actors 角色、Classes 职业、Enemies 敌人
      （可选：Troops 敌人队伍、CommonEvents 公共事件）
  CSV 用 utf-8-sig 编码，Excel 双击直接正常显示中文，一行一个 id。

  比如要查物品：打开 csv\Items_物品.csv，列是
      ID, 名称, 说明, 效果, 伤害, 特性, 价格, 消耗品, 使用场合, 影响范围,
      命中类型, 成功率, 使用次数, TP增加, 类别, 动画, 图标, 备注
  里面嵌套的东西已经翻成人话，例如：
      1, ===药品===, 恢复500点HP。, HP回复 +500%；解除状态#1 0%,
      伤害:无 公式:0 浮动:20% 会心:否 属性:0, ...

  没界面的环境（或想批量）可以直接用命令行：
      python src\xj_db.py                    列出所有表 + 行数
      python src\xj_db.py --out csv          默认 8 张表全转
      python src\xj_db.py --all --out csv    连 Troops/CommonEvents 一起转
      python src\xj_db.py Items Skills --out csv


【存银 / 物品计数校验为什么能随便改】
  1) 存银（界面里就叫“存银”，游戏里也是这个词）
     它是一个 Lock 对象，里面存了 @value（数值）和 @master（校验和）：

         @master = @value * 91 + 45 + seed / 800    （seed 在存档的 :system 分区）

     读存银时它会验算一遍，不相等就弹「游戏异常！」然后退出。
     本工具改 @value 时会自动把 @master 一起重算。

  2) 背包里每件物品都有一个“计数校验”
     存档的 :party 里有一堆 Change 对象（key 是“7:物品id” 这种字符串），
     value 是 AES-128-ECB 加密后的一串16进制（密钥 admin_1941344749），
     明文 = “物品id:数量” 拼起来的字符串。
     游戏存/读档时会拿它跟背包实际内容对账，对不上就是“数据异常”。
     所以本工具添加/删除物品时会重算所有 Change；
     也可以随时点「同步物品计数校验」手动对一次账。

  3) 周期检查（脚本里的 $jiance）
     游戏每隔一阵会检查 @cheated 之类的作弊标记和关键词，
     体检不过也会弹异常。点「体检」会告诉你哪项不对，
     「一键按规则修复」按游戏自己的规则修，「清除作弊标记」直接清理干净。

  万一你还是看到了「游戏异常！」：
    回到工具里点一次「体检」→「一键按规则修复」→「保存」，再进游戏。


【想改的字段在哪儿（「全部解析数据」页）】
  :party    → 存银、@actors 队伍成员、@items 背包、@steps 步数
              @items 是 4 页×20 格：@data[页号*20+格号]，0 表示空格
  :actors   → @data[角色id] → @name 名字、@level 等级、@hp、@mp、@exp 经验
              @attr → @体质 @法力 @力量 @耐力 @敏捷 @潜能 @人气 @贡献 @体力 @活力
              @babies → 召唤兽列表（每个里面又有 @level/@hp/@loyalty/@life 等）
  :switches → @data[开关编号]  （编号从 0 开始）
  :variables→ @data[变量编号]
  直接在上面搜索框里输“存银 / @gold / 体质 / 召唤兽”就能跳过去。


【出问题了怎么办】
  * 存档坏了：把同目录下的 save.rvdata2.bak.<时间戳> 改回 save.rvdata2 即可。
  * 提示解密失败：可能是游戏更新过、换了密钥，见 docs\逆向过程.md 里的爆破工具。
  * 界面报错：详细信息会写进仓库目录的 error.log，把它发出来即可。
  * 只改存档是安全的：游戏只对 Game.exe 和 System\main.dll 做 md5 校验，
    不会校验存档本身。
